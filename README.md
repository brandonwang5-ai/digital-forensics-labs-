# Digital Forensics & Incident Response Labs
This repository contains a curated selection of academic digital forensics and Incident Response labs completed as part of my M.S in Cybersecurity   

The labs demonstrate my hands on experience with:
- Digital evidence acquisition and analysis
- Incident response investigations
- Chain of custody and evidence documentation
- Disk, memory, network, and log forensics
- Forensic tools such as Autopsy, E3, FTK Imager, Wireshark, and Splunk

Each folder contains a concise case summary outlining the investigative question, tools used, key findings, and conclusions.

  Note: All work shown was conducted in a controlled academic lab environment using provided datasets and scenarios.
